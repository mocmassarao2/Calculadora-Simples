# 🧮 Calculadora Simples em React

Uma calculadora interativa desenvolvida com **React**, **TypeScript** e **CSS Modules**. O projeto permite realizar as quatro operações matemáticas básicas utilizando um menu de seleção (`<select>`).

---

## 🚀 Funcionalidades

* ➕ Soma
* ➖ Subtração
* ✖️ Multiplicação
* ➗ Divisão (com validação para evitar divisão por zero)
* 🧹 Botão para limpar os campos
* 📱 Interface moderna e centralizada na tela

---

## 🛠️ Tecnologias Utilizadas

* [React](https://react.dev/)
* [TypeScript](https://www.typescriptlang.org/)
* [Vite](https://vitejs.dev/)
* CSS Modules
